# Otthoni edzésnapló

## GitHub Pages telepítés
1. Csomagold ki a ZIP-et.
2. A benne lévő fájlokat (`index.html`, `app.js`, `manifest.json`, `sw.js`, `icon.svg`) töltsd fel a GitHub repository gyökerébe.
3. GitHub → Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
4. Nyisd meg a Pages URL-t telefonon. Android/Chrome menü → „Telepítés” vagy „Hozzáadás a kezdőképernyőhöz”.

## Tartalom
- Heti A/B/C edzésterv
- Gyakorlatkönyvtár végrehajtási leírással, technikai tippekkel és alternatívákkal
- Edzésnapló helyi böngészős mentéssel
- JSON export
- Offline gyorsítótár

A gyakorlatábrák sematikus illusztrációk, nem helyettesítik a helyes technika elsajátítását.
Az edzésnapló adatai az adott böngészőben tárolódnak; böngészőadatok törlésekor elveszhetnek. Exportáld rendszeresen a naplót.
